# No third-party Python packages are required.
#
# scripts/run_pipeline.py uses only the standard library (argparse, pathlib,
# re, subprocess, time) and talks to PostgreSQL by invoking psql inside the
# Docker container, which the project already depends on.
#
# A database driver such as psycopg would be a reasonable alternative, but it
# would add an install step for behaviour this pipeline does not need: the SQL
# files do the work, and the script only sequences them and reports timings.
# This file is kept, empty of dependencies, so that the absence is explicit
# rather than looking like an oversight.
#
# Verified on Python 3.15.2 (the version installed on the machine this was
# built and run on).
